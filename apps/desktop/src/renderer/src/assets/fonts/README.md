# Bundled interface fonts

These WOFF2 files are bundled with the Electron renderer. The application does
not load interface fonts from a CDN.

- `Geist-Variable.woff2`: Geist Sans v1.7.1, from
  <https://github.com/vercel/geist-font/tree/v1.7.1/fonts/Geist/webfonts>
  (SHA-256 `2FFEBE993E969069A9789D15164B7715D42491B5835516C5E3B935D5F81B05F1`).
- `SourceHanSansSC-Variable.woff2`: Source Han Sans SC v2.005R, from
  <https://github.com/adobe-fonts/source-han-sans/tree/2.005R/Variable/WOFF2/OTF>
  (SHA-256 `085CC88C530B9C434165AB926F81608A55B24E60E05719F3D41340AC45D9C62F`).

Both fonts are distributed under the SIL Open Font License 1.1. Their license
texts are included alongside the font files.
